# hello-world-in-BASIC.
This is NOT a esolang language. BASIC stands for Beginner's All-purpose Symbolic Instruction Code. BASIC is really easy. This prints hello world. To make it loop hello world you make the "20 END" the "20 GOTO 10." .  The logic is that the first command started with 10 and the second one was twenty, and then the 20 said 20 GOTO 10.
