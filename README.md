# hello-world-in-BASIC.
This is NOT a esolang language. BASIC stands for Beginner's All-purpose Symbolic Instruction Code. BASIC is really easy. This prints hello world. To make it loop hello world you make the "20 END" the "20 GOTO 10." .  The logic is that the first command started with 10 and the second one was twenty, and then the 20 said 20 GOTO 10. GOTO means Go to this, and in this case since it says 10 after GOTO it "goes to" that command. The 10 command is the printing command since at the beginning of the printing command it has "10" at the beginning, and print then "hello world" the logic for that is that print means to display the text and the quotation marks then the text send to the print command to display the text inside the quotation marks.
